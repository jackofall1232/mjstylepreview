# MJ Style Preview

Standalone WordPress hairstyle consultation plugin for MJHairArtist.com.

- Installable release: [mj-style-preview.zip](mj-style-preview.zip)
- Installation, configuration, shortcode, privacy, API contract and v2 recommendations: [Plugin guide](mj-style-preview/README.md)
- Test evidence and remaining staging checks: [TESTING.md](TESTING.md)
- Plugin source: `mj-style-preview/`
- Local test fixtures (never included in the release): `tests/`

Use `[mj_style_preview]` on any normal WordPress page. Configure under Settings → MJ Style Preview. Disabled by default; API credentials stay server-side.
